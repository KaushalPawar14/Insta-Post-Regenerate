# Python dependencies for this Vercel Service's file-based functions.
#
# IMPORTANT: do not add a Python ASGI/WSGI web dependency here. This service
# has no single `app`/`application` entrypoint -- Vercel resolves each .py
# file in this directory as its own function, and adding one would make
# Vercel's framework auto-detection try to treat this as that framework's app
# instead, breaking the four separate function routes.
#
# (Also avoid literally naming such dependencies in this file's comments --
# Vercel's framework auto-detection scans this file's raw text, and it will
# false-positive on the name appearing in a comment just as readily as on a
# real dependency line. Learned the hard way: an earlier version of this
# comment named the frameworks to avoid and that alone made deployment fail
# with "Multiple frameworks detected in project root".)
#

#   - langchain-groq  REMOVED: verified genuinely unused (no reference in
#                     agent_1/2/3 or main.py/state.py; only an orphan
#                     requirements line and an unused GROQ_API_KEY).
#   - langgraph       REMOVED: in-process StateGraph orchestration is replaced
#                     by QStash message chaining, since each stage now runs in
#                     its own stateless function invocation.
#   - python-dotenv   REMOVED: Vercel injects environment variables directly.
#   + supabase        ADDED: replaces the data_vault/ disk writes.
#   + qstash          ADDED: per-stage job orchestration.
#   + openai          ADDED: was an implicit transitive dep of the original
#                     agent_3 (it imported `from openai import OpenAI`).
