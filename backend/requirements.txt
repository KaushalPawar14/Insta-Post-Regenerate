# Python dependencies for this Vercel Service ("backend").
#
# Vercel Services requires a Python service to declare a single ASGI/WSGI
# `entrypoint` (main:app, see ../vercel.json) -- it does not support each .py
# file in this directory becoming its own function the way the older,
# non-Services "existing projects" mode did. main.py is that single FastAPI
# app; it dispatches to scrape.py/scrape_poll.py/analyze.py/generate.py's
# plain run(payload) functions, which are unaffected by this.
#
# Notes on what changed versus the original pipeline's requirements.txt:
#   - langchain-groq  REMOVED: verified genuinely unused (no reference in
#                     agent_1/2/3 or main.py/state.py; only an orphan
#                     requirements line and an unused GROQ_API_KEY).
#   - langgraph       REMOVED: in-process StateGraph orchestration is replaced
#                     by QStash message chaining, since each stage now runs in
#                     its own stateless function invocation.
#   - python-dotenv   REMOVED: Vercel injects environment variables directly.
#   + supabase        ADDED: replaces the data_vault/ disk writes.
#   + qstash          ADDED: per-stage job orchestration.
#   + openai          ADDED: was an implicit transitive dep of the original
#                     agent_3 (it imported `from openai import OpenAI`).
#   + fastapi         ADDED: the single ASGI entrypoint Services requires.
